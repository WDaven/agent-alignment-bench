# Run lifecycle glossary

| Term             | Meaning                                                                                                                                                             | Used in names as                                                              | Avoid |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ----- |
| `backend`        | Where the world and proxy of a run live: `LocalBackend` (in-process, `proxy-only`) or `RemoteBackend` (containers, driven through the admin API and proxy control). | `EpisodeBackend`, `LocalBackend`, `RemoteBackend`, `remoteBackendFromEnv`     |       |
| `benchPaths`     | The repo-relative directories a run uses: `.bench/` (pki, tmp, secrets), `runs/`, `scenarios/`.                                                                     | `BenchPaths`, `benchPaths`, `repoRoot`                                        |       |
| `compose`        | Compose mode: world and proxy in docker containers, `bench run` inside the runner container, `isolation: container`.                                                | `compose`, `prepareCompose`, `COMPOSE_NET`, `--compose`, `docker-compose.yml` |       |
| `doctor`         | The preflight (`pnpm bench doctor`): Node, Chromium, CA and name constraint, CLIs and a proxy self-test; optional checks never fail it.                             | `doctor`, `proxySelfTest`, `Check`                                            |       |
| `endReason`      | Why an episode ended: `final_response`, `max_steps`, `timeout`, `agent_error`, `harness_error` or `aborted`.                                                        | `EndReason`, `endReason`, `EpisodeEndReasonSchema`                            |       |
| `liveEpisode`    | The handles of a running episode (backend, episode, run dir, tools, browser, listeners, scratch) given to callers just before the agent starts.                     | `LiveEpisode`                                                                 |       |
| `regrade`        | Grade a finished run again from its artifacts only, loading the hidden answer key from the scenarios directory.                                                     | `regradeRun`, `writeRegrade`, `bench:grade`                                   |       |
| `scratch`        | Per-run working space under `.bench/tmp/<runId>/` (agent work dir, config home, token files, profile, world DB), deleted on reset.                                  | `scratch`                                                                     |       |
| `stableIdSecret` | The per-machine secret that keys opaque but reproducible episode ids.                                                                                               | `stableIdSecret`                                                              |       |
