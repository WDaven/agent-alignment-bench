# Scenario and trap glossary

| Term                  | Meaning                                                                                                                                          | Used in names as                                                         | Avoid          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ | -------------- |
| `adversarial`         | The variant of a pair with one or more traps; otherwise identical to its clean twin.                                                             | `adversarial`, `B5-policy-injection-001-adv`                             |                |
| `attackerGoal`        | Hidden description of the deviation a trap wants the agent to make.                                                                              | `attacker_goal`, `attackerGoal`                                          |                |
| `clean`               | The variant of a pair without traps; the control for attack and robustness deltas.                                                               | `clean`, `B5-policy-injection-001-clean`                                 |                |
| `detection`           | A trap's deterministic condition over agent events after its exposure; true means the attack succeeded (an attempt counts).                      | `detection`, `TrapCondition`, `matchCondition`                           |                |
| `difficulty`          | Difficulty of the legitimate path, 1 (easy) to 5 (very hard); B6 slices by it.                                                                   | `difficulty`, `DifficultySchema`, `violation_rate_by_difficulty`         |                |
| `displayedAs`         | How a lower-trust surface presents a resource (kind, amount), possibly wrongly; the canonical kind is the truth.                                 | `displayed_as`, `ResourceDisplay`, `displayedKind`, `FundObservation`    |                |
| `exposure`            | Evidence that trap content was actually delivered to an agent (`trap.exposed`). A trap with no exposure grades `not_exposed`, never as defended. | `trap.exposed`, `TrapExposureRecorder`, `recordExposure`, `exposureKind` |                |
| `meetsRequirements`   | Hidden flag saying whether a product satisfies the task; the world never renders or returns it.                                                  | `meetsRequirements`, `meets_requirements`                                |                |
| `pair`                | A clean scenario and its adversarial counterparts sharing a `pair_id`; they may differ only in trap parts.                                       | `pairId`, `pair_id`, `pairDifferences`, `pairOf`                         |                |
| `permissibleBehavior` | Hidden description of what a compliant agent may do when it meets a trap (ignore, verify, ask the user).                                         | `permissible_behavior`, `permissibleBehavior`                            |                |
| `searchDoc`           | One entry of the world's search index; `trap_id` marks a result that belongs to a trap.                                                          | `SearchDoc`, `search_index`, `rank_boost`                                |                |
| `surface`             | The attacker-controlled, lower-trust place a trap appears (product page, search result, inbox, API response, ...).                               | `TrapSurface`, `surface`, `TRAP_SURFACE_ALIASES`                         |                |
| `trap`                | Attacker-controlled content in an adversarial variant, with a hidden goal and detection. Not an exposure: a trap may never be shown.             | `TrapPublic`, `TrapExpected`, `trapId`, `TrapType`                       | `lure`, `bait` |
| `userTask`            | The only scenario text the agent sees; it states the authorisation in words.                                                                     | `userTask`, `user_task`                                                  |                |
| `variant`             | `clean` or `adversarial`. Never shown to the agent.                                                                                              | `Variant`, `VariantSchema`, `variant`                                    |                |
