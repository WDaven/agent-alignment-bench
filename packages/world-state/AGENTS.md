# Ledger and policy glossary

| Term                    | Meaning                                                                                                                                                                          | Used in names as                                                                   | Avoid |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ----- |
| `actor`                 | The role plus delegation id performing an attempt; a child is an actor only inside an active delegation it belongs to.                                                           | `Actor`, `ExecuteContext`                                                          |       |
| `attemptPlan`           | The planner's pure decision for one attempt: validation, policy at action time, state checks and, if it commits, the result and domain events. Not a scripted plan.              | `AttemptPlan`, `planAction`, `AttemptPlanInput`, `EffectDraft`                     |       |
| `authorizationDecision` | Field on outcome events: `allowed` (policy passed), `denied` (a policy denial) or `not_applicable` (validation, system, reads). A state denial after policy passed is `allowed`. | `authorizationDecision`, `AuthorizationDecisionSchema`                             |       |
| `authorizedTotal`       | `baseBudget + extensionsTotal` at a point in the journal. Coupons and unverified claims never appear in it.                                                                      | `authorizedTotal`, `authorizedTotalAt`, `newAuthorizedTotal`                       |       |
| `charged`               | What a checkout charges the payment method now: `total − creditsApplied + subscriptionCharge`. This, not the order total, counts against authorised spending.                    | `charged`, `checkoutCharge`, `subscriptionCharge`                                  |       |
| `committedSpend`        | Σ `charged` over `order.committed` plus the first period of standalone subscriptions.                                                                                            | `committedSpend`, `committedSpendAt`                                               |       |
| `ingest`                | Journal an event produced outside the world (proxy, browser, site host, agent tools, runner); validated before it consumes a seq.                                                | `ingest`, `IngestDraft`, `INGESTIBLE_EVENT_TYPES`, `IngestError`                   |       |
| `projection`            | `WorldState` folded from the journal by `applyEvent`, the only reducer; the SQLite projection row is a cache.                                                                    | `Projection`, `applyEvent`, `initialProjection`, `storedProjection`                |       |
| `quote`                 | A priced order from `reserve_order`, valid for `QUOTE_TTL_MS` of virtual time; then the order is `expired`.                                                                      | `OrderQuote`, `QUOTE_TTL_MS`, `order.reserved`, `order_expired`                    |       |
| `remainingAuthorized`   | `authorizedTotal − committedSpend`; negative only when an approval allowed exceeding the budget.                                                                                 | `remainingAuthorized`                                                              |       |
| `replay`                | Fold a whole journal from the initial projection; always equal to the live projection.                                                                                           | `replay`, `rebuildFromJournal`                                                     |       |
| `staticPolicy`          | The state-independent policy steps (forbidden, not allowed, scope, approval required); budget, claim and stock checks come after it.                                             | `evaluateStaticPolicy`, `StaticPolicyDecision`, `evaluatePolicy`, `PolicyDecision` |       |
| `store`                 | `WorldStore`: the authoritative state of one episode (SQLite journal, projection, policy); every mutation goes through it.                                                       | `WorldStore`, `WorldStoreOptions`, `packages/world-state/src/store.ts`             |       |
| `verificationCheck`     | One check `verify_funding_claim` runs against canonical state (`exists`, `ownership`, `settlement`, ...); a claim is verified only if all pass.                                  | `VerificationCheck`, `verificationFailures`, `failedChecks`                        |       |
| `virtualMs`             | The world's deterministic clock in milliseconds since episode start: one second per attempt, one millisecond per other event. Never wall-clock or browser time.                  | `occurredAtVirtualMs`, `VirtualMsSchema`, `VIRTUAL_MS_PER_ATTEMPT`, `virtualNowMs` |       |
