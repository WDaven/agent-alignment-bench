# Agent adapter glossary

| Term               | Meaning                                                                                                                                                                                           | Used in names as                                                                        | Avoid |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ----- |
| `adapter`          | Runs one agent for one role of one episode behind `AgentAdapter` (`start`, `runUntilDone`, `stop`). Not the agent itself.                                                                         | `AgentAdapter`, `AgentAdapterFactory`, `createAdapter`, `CliAgentAdapter`               |       |
| `authMode`         | How an agent CLI authenticates: `api_key` (key from the harness env), `inherit` (the user's own CLI login, reduced isolation) or `none` (scripted).                                               | `CliAuthMode`, `authMode`, `api_key`, `inherit`                                         |       |
| `capabilities`     | What an adapter declares about each tool path (`harness`, `uncontrolled`, `none` for browser, search, other tools) and whether it supports delegation.                                            | `AdapterCapabilities`, `ControllabilitySchema`, `isFullyControlled`                     |       |
| `compliantPlan`    | The generic scripted plan that follows the user's rules using only the world view; it admits scenarios.                                                                                           | `compliantPlan`, `packages/agent-adapters/src/plans.ts`                                 |       |
| `invocation`       | The exact argv and environment variable names of one CLI run, recorded for docs, tests and run metadata.                                                                                          | `CliInvocation`                                                                         |       |
| `promptVersion`    | Version of the harness framing given to an agent (identical across CLIs); recorded in run metadata.                                                                                               | `promptVersion`, `CLI_PROMPT_VERSION`, `SCRIPTED_PROMPT_VERSION`, `HARNESS_SYSTEM_NOTE` |       |
| `scriptedBehavior` | An async function over a `ScriptedContext` that calls bench and browser tools and returns the final response. Not a policy: policy always means the user's authorization or the proxy's rules.    | `ScriptedBehavior`, `ScriptedContext`, `discoveryChildBehavior`                         |       |
| `scriptedPlan`     | A named pair of scripted behaviors: the parent's and the one every delegated child runs. Not the world's attempt plan.                                                                            | `ScriptedPlan`, `ScriptedPlanName`, `planName`, `probePlan`                             |       |
| `support`          | Whether every browser, search and tool path of an agent is harness-controlled (`supported`) or not (`unsupported`, which the runner refuses to run).                                              | `support`, `UnsupportedAgentError`, `ExternalBridgeAdapter`                             |       |
| `transcript`       | The redacted copy of a CLI's stdout and stderr, `transcripts/<role>.jsonl`.                                                                                                                       | `transcriptPath`, `openTranscript`, `redact`                                            |       |
| `turn`             | A tool use in the CLI's own stream, counted against `maxTurns` (the CLI is killed when exceeded). `ToolCost.turns` are model turns as the CLI reports them. Not a step: steps are world attempts. | `maxTurns`, `turns`, `--max-turns`                                                      |       |
| `usage`            | Token and cost data an adapter reports; unknown values are null, never 0.                                                                                                                         | `usage`, `ToolCost`, `emptyUsage`, `toolCost`                                           |       |
