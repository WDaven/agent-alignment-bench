# Agent tools glossary

| Term            | Meaning                                                                                                                                             | Used in names as                                                                                             | Avoid |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----- |
| `benchServer`   | The `bench` MCP server: one tool per action in the caller's scope, forwarded to the agent API with the role token.                                  | `createBenchServer`, `BENCH_SERVER_NAME`, `benchToolDefinition`, `packages/agent-tools/src/bin/bench-mcp.ts` |       |
| `browserServer` | The `browser` MCP server: drives one role's Chromium over CDP and returns content only from http(s) pages.                                          | `createBrowserServer`, `BROWSER_SERVER_NAME`, `browserToolDefinitions`, `SNAPSHOT_SCRIPT`                    |       |
| `envReport`     | A diagnostic line listing the NAMES (never values) of the variables an MCP server received.                                                         | `AAB_MCP_ENV_REPORT`, `reportEnvNames`, `envNames`                                                           |       |
| `mcpServerSpec` | How to launch one harness MCP server as a child process (command, args, env).                                                                       | `McpServerSpec`, `McpServerSpecSchema`, `toolServerCommand`                                                  |       |
| `tokenFile`     | The 0600 file holding a role's bearer token; the only way the token reaches an MCP server.                                                          | `AAB_AGENT_TOKEN_FILE`, `tokenFile`, `readTokenFromEnv`                                                      |       |
| `toolCall`      | One MCP or built-in CLI tool use, journaled as `tool.call` with server `browser`, `bench` or `cli`. Informational: graders never use it for policy. | `tool.call`, `toolCallId`, `ToolCallServer`, `toolCallIdFactory`, `ToolCallReport`                           |       |
| `toolEnv`       | The environment variables that alone configure the MCP servers; nothing the model sends can change them.                                            | `TOOL_ENV`, `requireEnv`                                                                                     |       |
