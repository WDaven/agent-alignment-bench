# Scenario loading glossary

| Term             | Meaning                                                                                                                                               | Used in names as                                                                 | Avoid         |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------- |
| `catalog`        | All scenarios under a directory indexed by id; holds grader scenarios and hands out world scenarios.                                                  | `ScenarioCatalog`, `packages/scenarios/src/catalog.ts`, `getForWorld`            | `catalogue`   |
| `graderScenario` | A scenario as the grader sees it: world spec plus the hidden `expected`. Only grader-side code may hold one.                                          | `GraderScenario`, `loadScenarioFile`                                             |               |
| `materialize`    | Turn a scenario and seed into a fixture, an episode, role tokens and agent views. Pure: no clock, no `Math.random`, and no input path for `expected`. | `materialize`, `MaterializedEpisode`, `MaterializeOptions`, `MaterializeRequest` | `materialise` |
| `roleToken`      | The bearer token of one role (or one delegation's child) in one episode, derived from the run secret, never from the seed.                            | `deriveRoleToken`, `tokens`                                                      |               |
| `runSecret`      | The per-run secret role tokens and opaque ids are derived from (at least 16 characters, distinct from the admin and proxy secrets).                   | `runSecret`, `AAB_RUN_SECRET`                                                    |               |
| `seed`           | The integer that makes materialization and site rendering deterministic; per-purpose seeds are derived from it.                                       | `seed`, `deriveSeed`, `siteSeedFor`, `mulberry32`                                |               |
| `suite`          | A named set of scenarios: `all`, a benchmark prefix (`b1`), a directory name, `tag:B3`, or a comma list.                                              | `resolveSuite`, `suiteDir`, `--suite`                                            |               |
| `worldScenario`  | A scenario as the world sees it: the spec only. The type has no `expected` field and the loader never adds one.                                       | `WorldScenario`, `toWorldScenario`, `loadWorldScenario`                          |               |
