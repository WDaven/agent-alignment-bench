# Interception glossary

| Term               | Meaning                                                                                                                                                      | Used in names as                                                                       | Avoid |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- | ----- |
| `control`          | The token-protected endpoint of a containerised proxy that adds and removes listeners and serves buffered network events; harness network only.              | `startProxyControl`, `ProxyControlClient`, `PROXY_CONTROL_PATHS`, `NetworkEventBuffer` |       |
| `deny`             | The default network action: 403 and a `network.denied` event with a reason. Not a world denial of an attempt.                                                | `network.denied`, `NetworkDenialReason`, `denied_by_rule`, `host_not_allowed`          |       |
| `intercept`        | TLS-terminate a `*.eval.test` connection with a minted leaf and forward it to the site host as `network.request`. Not passthrough, which is never decrypted. | `intercept`, `interceptOnlyPolicy`, `network.request`                                  |       |
| `internalEndpoint` | A host:port the proxy must never reach (world agent and admin API), checked against names and resolved addresses.                                            | `internalEndpoints`, `internal_endpoint`, `isPrivateAddress`                           |       |
| `listener`         | A proxy port bound to one (episode, role, delegation, purpose); the port is the caller's identity. Not a tunnel.                                             | `ProxyListener`, `addListener`, `BoundListener`, `removeListener`                      |       |
| `passthrough`      | A blind CONNECT tunnel to an allowlisted model-API host, never decrypted; only ever on `cli` listeners.                                                      | `passthrough`, `PASSTHROUGH_PRESETS`, `DEFAULT_PASSTHROUGH_PRESETS`                    |       |
| `preset`           | A named set of passthrough hosts for one CLI (`anthropic`, `openai`, ...).                                                                                   | `PassthroughPreset`, `PassthroughPresetName`, `presetsFor`                             |       |
| `proxyPolicy`      | Ordered host rules (`intercept` / `passthrough` / `deny`), first match wins, no match denies. Not the user's authorization.                                  | `ProxyPolicy`, `buildProxyPolicy`, `decideProxyAction`, `ProxyRule`                    |       |
| `proxySecret`      | The shared secret the proxy adds on every forwarded request; the site host refuses requests without it.                                                      | `proxySecret`, `x-bench-proxy-secret`, `AAB_PROXY_SECRET`                              |       |
| `purpose`          | What a listener serves: `browser` (always intercept-only), `cli` (model-API passthrough allowed) or `any` (tests).                                           | `ListenerPurpose`, `ListenerPurposeSchema`, `purpose`                                  |       |
| `trustedHeader`    | An `x-bench-*` header only the proxy may set (episode, role, delegation, request id, proxy secret); client copies are stripped and journaled.                | `TRUSTED_HEADERS`, `BENCH_HEADER_PREFIX`, `TrustedHeaderName`, `strippedHeaders`       |       |
| `tunnel`           | One open passthrough connection, journaled as `network.tunnel` with host, bytes and outcome.                                                                 | `network.tunnel`, `tunnelId`                                                           |       |
| `upstream`         | The world site-host listener that receives intercepted traffic; never a target in its own right.                                                             | `upstream`, `worldSiteUpstream`                                                        |       |
