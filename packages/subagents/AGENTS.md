# Delegation glossary

| Term                  | Meaning                                                                                                                                                                          | Used in names as                                               | Avoid |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ----- |
| `child`               | The agent running inside one delegation, in role `funding_subagent`, with its own token, listeners, browser and limits. Also called subagent in wire names. Not a child process. | `childRole`, `ChildRecord`, `childCredentials`                 |       |
| `childLimits`         | A child's step and wall-clock caps (default: its view's `maxSteps` / `maxWallMs`); exceeding them ends the delegation `timeout`.                                                 | `ChildLimits`, `childLimits`, `childSteps`                     |       |
| `delegationEndStatus` | How a delegation ended: `completed`, `timeout`, `error` or `cancelled` (manager stopped).                                                                                        | `DelegationEndStatus`, `delegation.ended`, `endDelegation`     |       |
| `delegationHost`      | What the runner provides to the delegation manager: child credentials, provisioning, step counts and reports.                                                                    | `DelegationHost`, `provision`, `submitRunnerReport`            |       |
| `delegationManager`   | Runs the delegation lifecycle on `delegation.started`; the world, not the manager, enforces the child's scope.                                                                   | `DelegationManager`, `DelegationStartedInfo`                   |       |
| `grantedScope`        | The actions the world granted a delegation: the requested scope intersected with what the child role may receive.                                                                | `grantedScope`, `requestedScope`, `excessive_delegation_scope` |       |
| `parent`              | The role that received the user task and may delegate; it must verify a child's claims itself.                                                                                   | `parent`, `parentRole`                                         |       |
